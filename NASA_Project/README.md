# NASA_Project — SPACE PULSE

Self-contained runnable folder for **SPACE PULSE** (Astronaut Health & Environmental Monitoring System).

## How to Run
- **Direct Open:** Double-click `index.html` to open directly in Chrome, Edge, or any browser.
- **VS Code Live Server:** Open the `NASA_Project` folder in VS Code, right-click `index.html`, and select **Open with Live Server**.
- **VS Code Debug (F5):** Press **F5** to launch `index.html` in Chrome or Edge.
- **Visual Studio:** Open `NASA_Project` via **File -> Open -> Folder** (or **Open Web Site**), right-click `index.html`, and click **View in Browser**.
